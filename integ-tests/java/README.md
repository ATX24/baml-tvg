# BAML Java Integration Tests

Integration tests for the BAML Java client.

## Prerequisites

1. **Build libbaml_cffi**:
   ```bash
   cd ../../engine/language_client_cffi
   cargo build --release
   ```

2. **Set BAML_LIBRARY_PATH**:
   ```bash
   # Linux
   export BAML_LIBRARY_PATH=$(pwd)/../../engine/target/release/libbaml_cffi.so
   # macOS
   export BAML_LIBRARY_PATH=$(pwd)/../../engine/target/release/libbaml_cffi.dylib
   # Windows
   set BAML_LIBRARY_PATH=%CD%\..\..\engine\target\release\baml_cffi.dll
   ```

3. **Set API keys** (create `.env` in `integ-tests/`, or export in your shell):
   ```bash
   OPENAI_API_KEY=your_key_here
   ```

## Running Tests

1. **Build a compatible `baml-cli`** (must be `>= 0.219.0` for `output_type java`):
   ```bash
   cd ../../engine
   cargo build --release -p baml-cli
   ```

2. **Generate the Java client** (Java “hello world” BAML lives in `./baml_src/`):
   ```bash
   cd ../../integ-tests/java
   ../../engine/target/release/baml-cli generate --from ./baml_src
   ```

3. **Build the Java runtime** (if not already built):
   ```bash
   cd ../../engine/language_client_java
   mvn clean install
   ```

4. **Run tests**:
   ```bash
   cd ../../integ-tests/java
   # If you used integ-tests/.env, load it into your shell:
   set -a && source ../.env && set +a
   mvn test
   ```

## Test Structure

- `src/test/java/WorkflowTest.java` - Basic workflow tests including `LLMEcho("Hello, world!")`
- Generated client code is in `baml_client/` (generated by `baml-cli generate`)

## Notes

- The Java runtime library (`baml-runtime-java`) must be built and available
- The generated client code references `BamlRuntime` from `com.boundaryml.baml`
- Encoder/decoder helpers (`BamlEncoder`, `BamlDecoder`) are currently implemented for the `LLMEcho` smoke test
